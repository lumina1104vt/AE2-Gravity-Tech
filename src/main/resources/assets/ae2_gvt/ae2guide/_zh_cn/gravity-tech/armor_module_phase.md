# 穿墙模块

<Row>
<ItemImage id="ae2_gvt:armor_module_phase" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_phase" />
</Row>

## 效果

飞行时可以穿过方块。

## 使用方法

装在**反重力护腿**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[推进核心](propulsion_core.md)。

小提示：不想穿墙时，在模块界面把它关掉。
