# 免跳上阶模块

<Row>
<ItemImage id="ae2_gvt:armor_module_step_assist" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_step_assist" />
</Row>

## 效果

不用跳就能直接走上一格高的方块。

## 使用方法

装在**反重力靴子**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[推进核心](propulsion_core.md)。

小提示：数值可以在 `config/ae2_gvt-common.toml` 调整。
