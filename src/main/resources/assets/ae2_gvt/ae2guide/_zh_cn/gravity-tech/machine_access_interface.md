# 机器接入接口

<Row>
<ItemImage id="ae2_gvt:machine_access_interface" scale="4" />
<RecipeFor id="ae2_gvt:machine_access_interface" />
</Row>

贴在机器上的 AE2 线缆部件，让机器接上 ME 网络，不占频道。它的方块版本是 <ItemLink id="ae2_gvt:machine_access_block" />，可以从远处绑定机器。

## 两种模式

在右上角切换：

| 模式 | 作用 |
| :--- | :--- |
| **供应器** | 双星中枢的样板用它把材料送进机器、把产物收回。每台机器各有自己的阻挡模式、放入方式、配对编号、副方块范围和红石脉冲 |
| **ME 接口** | 像 ME 接口一样，给每台机器设定要维持的物品与数量，由网络补给。中枢不会使用这些机器 |

## 界面

- 上面一排是它代表的机器，一台一格，下面是各自的“机器（选填）”栏位。点一下选中，双击在世界里高亮。机器多时可以翻页。
- **应用到所有相同的机器**：供应器模式下，左侧工具栏有一个两个方框叠在一起的按钮（列表里有另一台相同机器时才出现）。例如连了 12 台粉碎机，设置好其中一台后按它，另外 11 台一起设成一样的（空栏位也会复制）。“相同”指同一种方块；辅助仓口不会被改到。
- 下面是选中那台机器的内容。ME 接口模式中，设置格上方的齿轮：左键设置数量，Shift + 左键改成显示网络中的数量。
- 数量最多可以输入 2147483647。

小提示：贴片和方块可以在工作台上互相换回，一换一。
