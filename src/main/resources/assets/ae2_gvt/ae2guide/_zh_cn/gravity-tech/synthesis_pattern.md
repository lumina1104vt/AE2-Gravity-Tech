# 合成处理样板

</Row>

[双星样板终端](multiblocks/twin-star-hub.md)编码出来的样板。

## 使用方法

- 用法跟 AE2 的处理样板一样，另外记录要用哪一种机器。
- 放进双星调度中枢后，中枢通过<ItemLink id="ae2_gvt:machine_access_interface" />把材料送到那台机器。
- 还可以记录材料放完后要拿什么工具右键机器，以及部分材料要放进附近的哪些方块。
