# 湮灭 TNT

<Row>
<ItemImage id="ae2_gvt:annihilation_tnt" scale="3" />
</Row>

**危险物品。** 它不像 TNT 那样爆炸，而是把半径 64 格球体内的一切湮灭，**包括基岩**，而且什么都不掉落。

## 会发生什么

- 球体在几秒内由中心向外被抹除。
- 范围内的生物会受到致命打击：不死图腾能救玩家，装甲不行。冲击波会伤到 128 格。
- 范围内的黑洞、白洞会消失，而且**不会**留下混沌物质。
- 中心留下一道永久、无法破坏的**空间裂缝**。

## 空间裂缝

走进去会到“破碎星空”维度，那一侧有对应的裂缝可以回来。

小提示：不要在基地附近点燃。
