# 混沌物质与奇点

<Row>
<ItemImage id="ae2_gvt:chaos_matter" scale="3" /><ItemImage id="ae2_gvt:anti_singularity" scale="3" /><ItemImage id="ae2_gvt:paradox_quantum_entangled_singularity" scale="3" />
</Row>

三种要在世界里制作的材料。

| 材料 | 获取方式 |
| :--- | :--- |
| 混沌物质 | 炸掉黑洞或白洞 |
| 反奇点 | 把 AE2 的奇点丢到黑洞上 |
| 悖论量子纠缠态奇点 | 反奇点、奇点、悖论水晶粉丢在彼此 1.5 格内引爆，每组得 2 个 |

## 使用方法

- 重新制作[黑洞与白洞](../holes.md)需要混沌物质。
- 混沌物质也是[引力加工工厂](../gravity_processing_factory.md)的催化剂。

小提示：已经有混沌物质时，可以用核聚变发生器增产。
