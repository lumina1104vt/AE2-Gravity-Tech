# 引力约束器

[核聚变发生器](multiblocks/fusion-generator.md)里约束等离子体的方块。

## 使用方法

聚变室外围是 9×9×9 的立方体，内部 7×7×7：

| 位置 | 放什么 |
| :--- | :--- |
| 12 条边（含角落） | 结构框架 |
| 六个面 | 约束玻璃或结构框架，至少一个结构连接端口；能量接口按需要放 |
| 四面侧墙其中一面的正中央 | 核聚变控制器，面朝外 |
| 内部，紧贴六面墙的正中央 | **6 个引力约束器** |
| 内部其余空间 | 留空 |

小提示：约束器朝哪边放都可以，结构成形时会自己转向中心。
