# 合金

<Row>

引力科技的金属材料，用在装甲、中枢单元与机器零件。

## 使用方法

- 合金粉在[引力加工工厂](../gravity_processing_factory.md)做成合金锭。
- 合金板由三种合金锭一起制成。

小提示：[核聚变发生器](../multiblocks/fusion-generator.md)有批量生产的配方，用少量的锭和板做出很多。
