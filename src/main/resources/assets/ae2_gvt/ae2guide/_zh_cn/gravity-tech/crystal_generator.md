# 结晶粉发电机

<Row>
<BlockImage id="ae2_gvt:crystal_generator" scale="4" />
<RecipeFor id="ae2_gvt:crystal_generator" />
</Row>

最基本的发电设备：烧水晶粉，把电送进 ME 网络。

## 使用方法

- 用线缆接上 ME 网络。
- 放入引力、反引力或悖论水晶粉：在界面放进格子、手拿着粉对它右键，或用漏斗、管道输入。
- 网络有电时，它也会自己从网络取粉。

## 发电量

| 水晶粉 | 输出 | 燃烧时间 |
| :--- | ---: | ---: |
| 引力 | 2,000 FE/t | 2 秒 |
| 反引力 | 2,000 FE/t | 2 秒 |
| 悖论 | 4,000 FE/t | 2 秒 |

小提示：网络没电时手动放粉就能启动，可以拿来给引力子收集器供电。
