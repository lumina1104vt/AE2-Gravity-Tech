# 饱和模块

<Row>

## 效果

饥饿值不满时每秒回复 1 点，不消耗食物。

## 使用方法

装在**反重力头盔**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[生命核心](life_core.md)。
