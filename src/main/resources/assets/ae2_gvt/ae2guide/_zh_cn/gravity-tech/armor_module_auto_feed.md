# 自动进食模块

<Row>
<ItemImage id="ae2_gvt:armor_module_auto_feed" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_auto_feed" />
</Row>

## 效果

饥饿值降到 14（7 格鸡腿）以下时，自动吃背包里的食物。

## 使用方法

装在**反重力头盔**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[生命核心](life_core.md)。

小提示：它会吃找到的第一种食物，不想被吃掉的食物别带在身上。
