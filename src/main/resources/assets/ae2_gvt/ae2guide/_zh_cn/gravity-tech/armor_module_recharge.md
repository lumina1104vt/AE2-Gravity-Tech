# 充电模块

<Row>
<ItemImage id="ae2_gvt:armor_module_recharge" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_recharge" />
</Row>

## 效果

每秒用网络的电给身上的物品充电（每件最多 20,000 FE，1 AE = 2 FE）。

## 使用方法

装在**反重力胸甲**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[网络核心](network_core.md)。

小提示：装甲要先连上 ME 网络（见[反重力装甲](armor.md)）。
