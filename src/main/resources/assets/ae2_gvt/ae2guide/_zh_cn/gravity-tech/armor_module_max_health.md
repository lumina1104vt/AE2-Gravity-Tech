# 生命上限模块

<Row>
<ItemImage id="ae2_gvt:armor_module_max_health" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_max_health" />
</Row>

## 效果

最大生命值 +8（4 颗心）。

## 使用方法

装在**反重力胸甲**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[生命核心](life_core.md)。

小提示：数值可以在 `config/ae2_gvt-common.toml` 调整。
