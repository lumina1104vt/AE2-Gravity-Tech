# 闪避模块

<Row>
<ItemImage id="ae2_gvt:armor_module_evasion" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_evasion" />
</Row>

## 效果

受到攻击时有 15% 几率完全没事。

## 使用方法

装在**反重力护腿**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[冲击核心](impact_core.md)。

小提示：数值可以在 `config/ae2_gvt-common.toml` 调整。
