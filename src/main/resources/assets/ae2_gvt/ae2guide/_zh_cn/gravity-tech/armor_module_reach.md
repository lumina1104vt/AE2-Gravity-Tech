# 延伸互动距离模块

<Row>
<ItemImage id="ae2_gvt:armor_module_reach" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_reach" />

## 效果

方块与生物的触及距离 +3 格。

## 使用方法

装在**反重力头盔**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[感测核心](sensor_core.md)。

小提示：数值可以在 `config/ae2_gvt-common.toml` 调整。
