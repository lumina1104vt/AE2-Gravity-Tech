# 冲刺突进模块

<Row>
<ItemImage id="ae2_gvt:armor_module_dash" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_dash" />
</Row>

## 效果

按 **V** 朝视线方向冲刺，每 1.5 秒一次。

## 使用方法

装在**反重力靴子**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[推进核心](propulsion_core.md)。

小提示：按键可以在游戏的按键设置里改。
