# 机器连接器

让机器接入接口（贴在线缆上的，或单方块的 <ItemLink id="ae2_gvt:machine_access_block" />）从远端代表机器。

## 用法

1. 蹲下右键机器接入接口，选取它。
2. 右键机器，把你点的那一面连到这个接口；再右键同一台，解除。一个接口可以连多台（供应器模式不限，ME 接口模式最多 9 台）。
3. 蹲下右键空气，取消选取。

**Ctrl + 右键机器**：一次连接它周围所有相同的机器（同一种方块）。例如一排 12 台粉碎机，Ctrl + 右键其中一台，12 台一起连上。默认范围是以你点的那台为中心、半径 16 格的球内，一次最多 64 台，两个数字都能在设置档（`linkAllRadius`、`linkAllMax`）调整；已经连接的会跳过，超出的会提示还有几台没连上。Ctrl + 右键只会增加，不会解除；一般右键还是只连一台。ME 接口模式的 9 台上限照样有效。

连接器的右键比机器自己的右键优先，点到有界面的机器也只会连接。拿着它时，选取的接口会发光，被连接机器的面也会发光，并有细线相连。

机器要在同维度、64 格内，区块要有加载。接口的红石脉冲不用方块，机器会直接收到一个来自旁边的讯号，所以机器周围不用留空位。

## 制作

- 机器：引力加工工厂
- 材料：
  - 记忆卡 ×1
  - 无线接收器 ×1
  - 反引力电路板 ×2
