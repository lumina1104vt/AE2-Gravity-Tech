# 中枢单元

决定[双星调度中枢](twin-star-hub.md)能力的元件。

## 使用方法

- 先做空白单元，它是其他单元的基底。
- **黑洞合成单元**放进中枢的黑色格，提供合成；**白洞计算单元**放进白色格，提供合成 CPU。
- 等级依次是奇异、虚数、悖论、普朗克，各级数值见[中枢页面](twin-star-hub.md)的表格。

小提示：升级只要换单元，不用重建结构。
