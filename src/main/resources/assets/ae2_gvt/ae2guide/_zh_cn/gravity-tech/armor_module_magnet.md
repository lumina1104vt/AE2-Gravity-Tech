# 磁力吸取模块

<Row>

<RecipeFor id="ae2_gvt:armor_module_magnet" />

## 效果

把 8 格内的掉落物和经验球吸过来。

## 使用方法

装在**反重力胸甲**上：穿着装甲按 **K**，选那一件，把模块卡放进格子。在同一个界面可以随时关闭或拆下。

制作时需要[感测核心](sensor_core.md)。

小提示：按住潜行时不会吸取。
