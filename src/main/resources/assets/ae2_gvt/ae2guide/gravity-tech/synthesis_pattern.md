# Synthesis Processing Pattern

<Row>
<ItemImage id="ae2_gvt:synthesis_pattern" scale="4" />

</Row>

The pattern the [twin-star pattern terminal](multiblocks/twin-star-hub.md) encodes.

## How to use

- It works like AE2's processing pattern, and also records which machine to use.
- Put it into the twin-star hub; the hub sends the materials to that machine through a <ItemLink id="ae2_gvt:machine_access_interface" />.
- It can also record a tool to right click the machine with once the materials are in, and the nearby blocks that some materials go into.
