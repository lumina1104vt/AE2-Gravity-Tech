# Recharging Module

<Row>
<ItemImage id="ae2_gvt:armor_module_recharge" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_recharge" />
</Row>

## Effect

Every second, charges the items you carry from the network's power (up to 20,000 FE each, 2 FE per AE).

## How to use

Install it in the **Anti-gravity Chestplate**: wear the armor, press **K**, choose the piece and put the card in the slot. It can be switched off or taken out there at any time.

Needs the [Network Core](network_core.md) to craft.

Tip: The armor must be linked to an ME network (see [Antigravity Armor](armor.md)).
