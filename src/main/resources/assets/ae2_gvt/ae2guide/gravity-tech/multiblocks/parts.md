# Structure Parts

<Row>
<ItemImage id="ae2_gvt:machine_frame" scale="3" /><ItemImage id="ae2_gvt:structure_frame" scale="3" /><ItemImage id="ae2_gvt:containment_glass" scale="3" /><ItemImage id="ae2_gvt:energy_port" scale="3" />

The blocks multiblocks and machines are built from.

| Block | Used for |
| :--- | :--- |
| Machine frame | Crafting parts such as the energy port and the accretion generator |
| Structure frame | The edges and walls of the [fusion generator](fusion-generator.md) |
| Containment glass | The windows of the fusion generator |
| Energy port | Takes FE for the fusion generator and gives it back |
