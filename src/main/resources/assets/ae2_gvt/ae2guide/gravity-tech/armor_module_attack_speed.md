# Attack Speed Module

<Row>
<ItemImage id="ae2_gvt:armor_module_attack_speed" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_attack_speed" />
</Row>

## Effect

Attack speed +1.

## How to use

Install it in the **Anti-gravity Chestplate**: wear the armor, press **K**, choose the piece and put the card in the slot. It can be switched off or taken out there at any time.

Needs the [Impact Core](impact_core.md) to craft.

Tip: The number can be changed in `config/ae2_gvt-common.toml`.
