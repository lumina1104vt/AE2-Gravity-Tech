# Graviton Generator

Takes gravitons or anti-gravitons from the ME network to generate power.

## How to use

- Connect it to the ME network. The network needs gravitons (collect them with a Graviton Collector).
- It takes 1 per second and outputs 200,000 FE/t.
- The button on the left of the window switches what it takes: either kind, gravitons only, or anti-gravitons only.

The network itself needs power to hand out gravitons, so another power source (for example a Crystal Dust Generator) has to start the network first.
