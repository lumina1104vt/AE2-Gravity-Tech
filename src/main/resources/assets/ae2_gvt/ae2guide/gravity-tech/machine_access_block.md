# Machine Access Interface

<Row>
<BlockImage id="ae2_gvt:machine_access_block" scale="4" />
<RecipesFor id="ae2_gvt:machine_access_block" />
</Row>

The block form of the <ItemLink id="ae2_gvt:machine_access_interface" />. It does not sit against any machine: all of them are bound from a distance with the <ItemLink id="ae2_gvt:machine_link_tool" />.

## How to use

1. Place it and cable it to the ME network (no channel used).
2. Link machines with the linker, up to 64 blocks away in the same dimension.
3. Right click it: the screen and settings are those of the machine access interface.

| Mode | How many machines |
| :--- | :--- |
| Provider | No limit |
| ME interface | Up to 9 |
