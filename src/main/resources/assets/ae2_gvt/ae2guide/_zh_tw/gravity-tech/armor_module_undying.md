# 瀕死免死模組

<Row>
<ItemImage id="ae2_gvt:armor_module_undying" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_undying" />
</Row>

## 效果

受到致命傷害時改為保留一半生命，並給予短暫的生命恢復與傷害吸收。每 2 分鐘一次。

## 使用方法

裝在**反重力胸甲**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[生命核心](life_core.md)。

小提示：數值可以在 `config/ae2_gvt-common.toml` 調整。
