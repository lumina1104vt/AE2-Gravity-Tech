# 合金

引力科技的金屬材料，用在裝甲、中樞單元與機器零件。

## 使用方法

- 合金粉在[引力加工工廠](../gravity_processing_factory.md)做成合金錠。
- 合金板由三種合金錠一起製成。

小提示：[核融合發生器](../multiblocks/fusion-generator.md)有大量生產的配方，用少量的錠和板做出很多。
