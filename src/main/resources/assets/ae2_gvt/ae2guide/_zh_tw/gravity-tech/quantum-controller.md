# 量子控制器

量子控制器是 AE2 **ME 控制器**的量子版本：用法完全一樣，可以拼成相同的控制器結構，也能直接接受 FE，還能把多個網路**跨維度、遠距離**連成一體，共用整個網路的頻道。

<BlockImage id="ae2_gvt:quantum_controller" scale="4" />

## 畫面

右鍵打開的主畫面與 ME 控制器相同，顯示網路狀態，右上角另外寫著目前**剩餘的頻道**（尚未組網時可能顯示「頻道：無限」）。左側的齒輪進入**量子控制器設定**頁，用來設定角色與頻率；設定頁左上角的箭頭可回到主畫面。

## 角色

量子控制器有三種角色，在設定頁切換：

| 角色 | 說明 |
| :--- | :--- |
| **未啟用** | 當作一般的 ME 控制器使用 |
| **主控制器** | 這個頻率的網路主體，**同一個頻率只能有一個** |
| **從控制器** | 連到同頻率的主控制器，使用整個網路的頻道 |

- **主控制器**：整個頻率網路的中心，負責替網路提供頻道。
- **從控制器**：同頻率的從控制器會連到主控制器，兩邊的網路合併成一個——**不論多遠、在不在同一個維度**，只要兩側的區塊都已載入即可。從控制器那一側的線纜由它提供頻道，實際使用的是整個網路的頻道。
- **未啟用**：就是一個普通的 ME 控制器。

從控制器不會被 AE2 當作另一組獨立的控制器結構，因此**不會觸發 AE2 的控制器衝突**。如果某個從控制器沒有連上主控制器，它那一側就相當於「沒有控制器的網路」。

## 頻率

- 頻率由你自己命名，在設定頁上方的輸入框填寫。
- **名稱相同的控制器會互相連接**。
- 設定頁下方列出目前**已載入**的控制器正在使用的頻率，每個頻率旁標註主控制器與從控制器的數量，點一下就能採用該頻率。
- 「清除頻率」可以取消目前的頻率設定。

### 狀態提示

設定頁會顯示目前的連結狀態：

| 提示 | 含義 |
| :--- | :--- |
| 未連結 | 未啟用角色或未設定頻率 |
| 主控制器：已連結 %s 個從控制器 | 正常運作，已帶上若干從控制器 |
| 已連到主控制器，使用整個網路的頻道 | 從控制器已成功連上 |
| 同頻率找不到主控制器 | 這個頻率還沒有主控制器（或尚未載入） |
| 同頻率有多個主控制器 | 頻率衝突，需要只保留一個主控制器 |
| 連結失敗，等候對方載入 | 對端的區塊尚未載入 |
| 還沒有設定頻率 | 需要先為頻率命名 |

## 使用要點

1. 像搭 ME 控制器一樣擺出控制器結構（也可以與現有的 ME 控制器結構混用）。
2. 進設定頁選定角色：一處選**主控制器**，其他位置選**從控制器**。
3. 給它們填入**相同的頻率名稱**。
4. 確認兩端的區塊都已載入，跨維度的控制器就會併入同一個網路。

> 小提示：因為從控制器不計入 AE2 的控制器衝突，你可以用「一個主控制器 ＋ 多處從控制器」的方式，把分散在各地的基地網路統一到同一個頻道池。
