# 熔岩免疫模組

<Row>
<ItemImage id="ae2_gvt:armor_module_lava_immunity" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_lava_immunity" />
</Row>

## 效果

不受熔岩與火焰傷害，身上的火會立刻熄滅。

## 使用方法

裝在**反重力胸甲**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[生命核心](life_core.md)。
