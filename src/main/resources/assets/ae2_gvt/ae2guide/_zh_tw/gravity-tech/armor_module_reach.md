# 延伸互動距離模組

<Row>
<ItemImage id="ae2_gvt:armor_module_reach" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_reach" />
</Row>

## 效果

方塊與生物的觸及距離 +3 格。

## 使用方法

裝在**反重力頭盔**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[感測核心](sensor_core.md)。

小提示：數值可以在 `config/ae2_gvt-common.toml` 調整。
