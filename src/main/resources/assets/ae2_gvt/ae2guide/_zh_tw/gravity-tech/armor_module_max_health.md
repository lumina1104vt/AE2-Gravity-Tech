# 生命上限模組

<Row>
<ItemImage id="ae2_gvt:armor_module_max_health" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_max_health" />
</Row>

## 效果

最大生命值 +8（4 顆心）。

## 使用方法

裝在**反重力胸甲**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[生命核心](life_core.md)。

小提示：數值可以在 `config/ae2_gvt-common.toml` 調整。
