# 磁力吸取模組

<Row>
<ItemImage id="ae2_gvt:armor_module_magnet" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_magnet" />
</Row>

## 效果

把 8 格內的掉落物和經驗球吸過來。

## 使用方法

裝在**反重力胸甲**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[感測核心](sensor_core.md)。

小提示：按住潛行時不會吸取。
