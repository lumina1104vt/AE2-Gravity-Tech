# 穿牆模組

<Row>

<RecipeFor id="ae2_gvt:armor_module_phase" />
</Row>

## 效果

飛行時可以穿過方塊。

## 使用方法

裝在**反重力護腿**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[推進核心](propulsion_core.md)。

小提示：不想穿牆時，在模組畫面把它關掉。
