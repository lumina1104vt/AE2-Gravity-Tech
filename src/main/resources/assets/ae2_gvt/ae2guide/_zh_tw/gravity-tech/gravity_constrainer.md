# 引力約束器

[核融合發生器](multiblocks/fusion-generator.md)裡約束電漿的方塊。

## 使用方法

融合室外圍是 9×9×9 的立方體，內部 7×7×7：

| 位置 | 放什麼 |
| :--- | :--- |
| 12 條邊（含角落） | 結構框架 |
| 六個面 | 約束玻璃或結構框架，至少一個結構連接埠；能量接口依需要放 |
| 四面側牆其中一面的正中央 | 核融合控制器，面朝外 |
| 內部，緊貼六面牆的正中央 | **6 個引力約束器** |
| 內部其餘空間 | 留空 |

小提示：約束器朝哪邊放都可以，結構成形時會自己轉向中心。
