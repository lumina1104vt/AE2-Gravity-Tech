# 衝刺突進模組

<Row>
<ItemImage id="ae2_gvt:armor_module_dash" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_dash" />
</Row>

## 效果

按 **V** 朝視線方向衝刺，每 1.5 秒一次。

## 使用方法

裝在**反重力靴子**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[推進核心](propulsion_core.md)。

小提示：按鍵可以在遊戲的按鍵設定裡改。
