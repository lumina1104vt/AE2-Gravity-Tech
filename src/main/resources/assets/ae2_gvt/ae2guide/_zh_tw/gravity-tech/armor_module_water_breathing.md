# 水下呼吸模組

<Row>
<ItemImage id="ae2_gvt:armor_module_water_breathing" scale="4" />

## 效果

可以在水中呼吸。

## 使用方法

裝在**反重力頭盔**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[生命核心](life_core.md)。
