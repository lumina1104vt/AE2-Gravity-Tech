# 機器接入接口

<Row>
<ItemImage id="ae2_gvt:machine_access_interface" scale="4" />
<RecipeFor id="ae2_gvt:machine_access_interface" />
</Row>

貼在機器上的 AE2 線纜零件，讓機器接上 ME 網路，不佔頻道。它的方塊版本是 <ItemLink id="ae2_gvt:machine_access_block" />，可以從遠端綁定機器。

## 兩種模式

在右上角切換：

| 模式 | 作用 |
| :--- | :--- |
| **供應器** | 雙星中樞的樣板用它把材料送進機器、把產物收回。每台機器各有自己的阻擋模式、放入方式、配對編號、副方塊範圍和紅石脈衝 |
| **ME 接口** | 像 ME 接口一樣，替每台機器設定要維持的物品與數量，由網路補給。中樞不會使用這些機器 |

## 畫面

- 上面一排是它代表的機器，一台一格，下面是各自的「機器（選填）」欄位。點一下選中，雙擊在世界裡高亮。機器多時可以換頁。
- **套用到所有相同的機器**：供應器模式下，左側工具列有一顆兩個方框疊在一起的按鈕（清單裡有另一台相同機器時才出現）。例如連了 12 台粉碎機，設定好其中一台後按它，另外 11 台一起設成一樣的（空欄位也會複製）。「相同」指同一種方塊；輔助艙口不會被改到。
- 下面是選中那台機器的內容。ME 接口模式中，設定格上方的齒輪：左鍵設定數量，Shift + 左鍵改成顯示網路中的數量。
- 數量最多可以輸入 2147483647。

小提示：貼片和方塊可以在合成台上互相換回，一換一。
