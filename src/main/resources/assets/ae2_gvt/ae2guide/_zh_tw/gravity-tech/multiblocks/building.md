# 多方塊建造

引力科技的大型結構（例如[雙星調度中樞](twin-star-hub.md)、[核融合發生器](fusion-generator.md)、[太空電梯](space-elevator.md)）可以使用**多方塊建造器**自動搭建整個結構，也能一鍵拆除，並可直接從 ME 網路取材料（需要先綁定 ME 網路）。

## 使用方法

先把結構所需的**控制器**放在正確的位置（建造器以控制器為基準生成整座結構）。

| 操作 | 效果 |
| :--- | :--- |
| 潛行 ＋ 右鍵控制器 | 開始建造整座結構 |
| 潛行 ＋ 右鍵空氣 | 開啟／切換建造器模式 |
| 右鍵空氣 | 停止目前的建造 |

建造器會依結構定義逐塊放置，並即時提示缺少的材料（`缺少：%s`）、被擋住的方塊（`%s 格被阻擋：%s`）等。

## 建造器模式

在「建造器模式」畫面中可以組合開啟：

- **拆除**：拆除整個結構。
- **鏡像**：依鏡像方向建造（部分結構不支援，會提示「此結構無法鏡像建造」）。
- **無艙口**：建造時不放置艙口／接口類方塊。

## 從 ME 網路取料

- Shift ＋ 右鍵可以把建造器與 ME 網路綁定，之後物品資訊裡會顯示「已綁定 … 的 AE 網路」，就能直接從網路調取方塊。
- 未連接 ME 網路時會提示「無法連接綁定的 ME 網路，僅使用背包」，此時只會消耗玩家背包裡的材料。

## 指令（需權限）

| 指令 | 作用 |
| :--- | :--- |
| `/lmb list` | 列出目前維度中的多方塊結構 |
| `/lmb info <controller>` | 查看指定控制器的結構資訊、朝向、參數與未成形的原因 |
| `/lmb form <controller>` | 直接讓指定的控制器依結構定義成形（除錯／快速修復用） |
