# 湮滅 TNT

<Row>
<ItemImage id="ae2_gvt:annihilation_tnt" scale="3" />
</Row>

**危險物品。** 它不像 TNT 那樣爆炸，而是把半徑 64 格球體內的一切湮滅，**包含基岩**，而且什麼都不掉落。

## 會發生什麼

- 球體在幾秒內由中心向外被抹除。
- 範圍內的生物會受到致命打擊：不死圖騰能救玩家，裝甲不行。衝擊波會傷到 128 格。
- 範圍內的黑洞、白洞會消失，而且**不會**留下渾沌物質。
- 中心留下一道永久、無法破壞的**空間裂縫**。

## 空間裂縫

走進去會到「破碎星空」維度，那一側有對應的裂縫可以回來。

小提示：不要在基地附近點燃。
