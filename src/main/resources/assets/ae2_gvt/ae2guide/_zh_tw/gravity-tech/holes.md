# 黑洞與白洞

## 黑洞

黑洞是引力科技最基礎的方塊，既是引力水晶的母岩，也負責世界合成（例如反奇點）。

<BlockImage id="ae2_gvt:black_hole" scale="4" />

## 尋找黑洞

使用引力波探測器，它會像 AE2 原版的隕石羅盤一樣，帶你找到世界上的黑洞。

<ItemImage id="ae2_gvt:gravity_wave_detector" scale="4" /> <RecipeFor id="ae2_gvt:gravity_wave_detector" />

## 黑洞的破壞與再生

- 破壞黑洞：TNT 爆炸可以破壞黑洞，獲得渾沌物質。

- 再生黑洞：使用渾沌物質、奇點與 64 個引力水晶粉，再透過爆炸（TNT、苦力怕都可以），就能重新製造一個新的黑洞。

## 白洞

白洞與黑洞幾乎一致，是反引力水晶的母岩，但不負責世界合成。

<BlockImage id="ae2_gvt:white_hole" scale="4" />

## 白洞的生成與破壞

- 生成白洞：白洞不會在自然界生成，只能人工製造。使用渾沌物質、反奇點與 64 個引力水晶粉，再透過爆炸（TNT、苦力怕都可以），就能製造一個新的白洞。

- 破壞白洞：TNT 爆炸可以破壞白洞，獲得渾沌物質。
