# 中樞單元

決定[雙星調度中樞](twin-star-hub.md)能力的元件。

## 使用方法

- 先做空白單元，它是其他單元的基底。
- **黑洞合成單元**放進中樞的黑色格，提供合成；**白洞計算單元**放進白色格，提供合成 CPU。
- 等級依序是奇異、虛數、悖論、普朗克，各級數值見[中樞頁面](twin-star-hub.md)的表格。

小提示：升級只要換單元，不用重建結構。
