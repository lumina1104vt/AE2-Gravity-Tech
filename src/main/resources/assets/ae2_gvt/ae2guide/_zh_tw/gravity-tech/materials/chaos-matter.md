# 渾沌物質與奇點

<Row>
<ItemImage id="ae2_gvt:chaos_matter" scale="3" /><ItemImage id="ae2_gvt:anti_singularity" scale="3" /><ItemImage id="ae2_gvt:paradox_quantum_entangled_singularity" scale="3" />
</Row>

三種要在世界裡製作的材料。

| 材料 | 取得方式 |
| :--- | :--- |
| 渾沌物質 | 炸掉黑洞或白洞 |
| 反奇點 | 把 AE2 的奇點丟到黑洞上 |
| 悖論量子糾纏態奇點 | 反奇點、奇點、悖論水晶粉丟在彼此 1.5 格內引爆，每組得 2 個 |

## 使用方法

- 重新製作[黑洞與白洞](../holes.md)需要渾沌物質。
- 渾沌物質也是[引力加工工廠](../gravity_processing_factory.md)的催化劑。

小提示：已經有渾沌物質時，可以用核融合發生器增產。
