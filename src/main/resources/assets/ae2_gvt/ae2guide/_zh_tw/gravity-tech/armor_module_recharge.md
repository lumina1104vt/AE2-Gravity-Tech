# 充電模組

<Row>
<ItemImage id="ae2_gvt:armor_module_recharge" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_recharge" />
</Row>

## 效果

每秒用網路的電替身上的物品充電（每件最多 20,000 FE，1 AE = 2 FE）。

## 使用方法

裝在**反重力胸甲**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[網路核心](network_core.md)。

小提示：裝甲要先連上 ME 網路（見[反重力裝甲](armor.md)）。
