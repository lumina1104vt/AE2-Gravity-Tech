# 隨身工作台模組

<Row>
<ItemImage id="ae2_gvt:armor_module_portable_workbench" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_portable_workbench" />
</Row>

## 效果

按 **B** 隨時打開 3×3 工作台。

## 使用方法

裝在**反重力胸甲**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[網路核心](network_core.md)。

小提示：按鍵可以在遊戲的按鍵設定裡改。
