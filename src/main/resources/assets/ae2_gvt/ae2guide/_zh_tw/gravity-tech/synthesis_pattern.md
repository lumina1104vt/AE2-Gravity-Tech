# 合成處理樣板

<Row>

</Row>

[雙星樣板終端](multiblocks/twin-star-hub.md)編碼出來的樣板。

## 使用方法

- 用法跟 AE2 的處理樣板一樣，另外記錄要用哪一種機器。
- 放進雙星調度中樞後，中樞透過<ItemLink id="ae2_gvt:machine_access_interface" />把材料送到那台機器。
- 還可以記錄材料放完後要拿什麼工具右鍵機器，以及部分材料要放進附近的哪些方塊。
