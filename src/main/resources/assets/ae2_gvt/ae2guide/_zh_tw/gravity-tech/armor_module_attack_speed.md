# 攻擊速度模組

<Row>

<RecipeFor id="ae2_gvt:armor_module_attack_speed" />
</Row>

## 效果

攻擊速度 +1。

## 使用方法

裝在**反重力胸甲**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[衝擊核心](impact_core.md)。

小提示：數值可以在 `config/ae2_gvt-common.toml` 調整。
