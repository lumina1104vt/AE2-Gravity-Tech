# 中鍵下單模組

<Row>
<ItemImage id="ae2_gvt:armor_module_pick_craft" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_pick_craft" />
</Row>

## 效果

對方塊按中鍵，從 ME 網路取一組到手上。網路裡沒有但有樣板時，會打開 AE2 的下單畫面。

## 使用方法

裝在**反重力頭盔**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[感測核心](sensor_core.md)。

小提示：裝甲要先連上 ME 網路（見[反重力裝甲](armor.md)）。
