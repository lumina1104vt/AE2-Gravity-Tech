# 雙星調度中樞

以黑洞與白洞為核心的多方塊結構，不僅有合成的功能，還有合成 CPU 的功能。整個結構的大小為 **235 × 235，高 121**，放置時請注意周圍的空間，確保雙星調度中樞可以成形。

## 雙星的使用

想要使用雙星調度中樞，首先你需要在結構中放置一個結構連接埠（取代控制器上方下極塔的任意一格中樞石柱），並且連上 ME 網路；其次，在雙星調度中樞裡放入黑洞單元與白洞單元，讓它擁有合成與合成 CPU 的功能；最後，向其中放入樣板就可以正常使用了。

下面是兩個單元所提供的功能：

| 組成部分 | 提供的功能 |
| :--- | :--- |
| 黑洞單元 | 合成 |
| 白洞單元 | 合成 CPU |

小提示：雙星調度中樞畫面頂部會顯示樣板數、任務數、CPU 數、並行、容量與目前的使用量。

## 等級

等級由**你放入的黑洞／白洞單元**決定，可以隨時更換升級，不需要重建結構。

| 等級 | 名稱 | 黑洞合成單元容量 | 白洞計算單元並行 |
| :--- | :--- | ---: | ---: |
| 1 | 奇異 | 32,767 | 127 |
| 2 | 虛數 | 2,147,483,647 | 32,767 |
| 3 | 悖論 | 140,737,488,355,327 | 8,388,607 |
| 4 | 普朗克 | ∞（無限） | ∞（無限） |

## 雙星調度中樞的功能

雙星調度中樞擁有極其強大的功能，可以處理循環配方、機率配方與遞迴配方。另外，在雙星下單畫面還可以設定「只做缺少的量／能做多少做多少／規劃完直接開始」，點「規劃 →」查看規劃結果：每個物品的次數、庫存、缺少的量、共用與樣板數，以及容量佔用與並行數。你也可以打開「合成圖」查看配方樹的流向、循環與副產物，或用「理論層」預估路線與成本。
