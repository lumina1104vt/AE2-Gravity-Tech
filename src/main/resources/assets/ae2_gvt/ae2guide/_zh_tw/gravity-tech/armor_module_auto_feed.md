# 自動進食模組

<Row>
<ItemImage id="ae2_gvt:armor_module_auto_feed" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_auto_feed" />
</Row>

## 效果

飢餓值降到 14（7 格雞腿）以下時，自動吃背包裡的食物。

## 使用方法

裝在**反重力頭盔**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[生命核心](life_core.md)。

小提示：它會吃找到的第一種食物，不想被吃掉的食物別帶在身上。
