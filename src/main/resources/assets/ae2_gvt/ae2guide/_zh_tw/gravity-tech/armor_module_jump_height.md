# 跳躍高度模組

<Row>
<ItemImage id="ae2_gvt:armor_module_jump_height" scale="4" />
<RecipeFor id="ae2_gvt:armor_module_jump_height" />
</Row>

## 效果

跳得更高（跳躍力 +0.25，原本是 0.42）。

## 使用方法

裝在**反重力靴子**上：穿著裝甲按 **K**，選那一件，把模組卡放進格子。在同一個畫面可以隨時關閉或拆下。

製作時需要[推進核心](propulsion_core.md)。

小提示：數值可以在 `config/ae2_gvt-common.toml` 調整。
